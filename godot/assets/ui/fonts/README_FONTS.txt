Main Menu Fonts (Title)
======================

The reference menu uses a sci-fi/tech display font (Bank Gothic / Eurostile vibe).
This repo does NOT ship fonts by default. To upgrade the title instantly:

Option A (FREE, recommended):
- Orbitron (Google Fonts, OFL)
  Download from: `https://fonts.google.com/specimen/Orbitron`
  Put a .ttf here, e.g.:
    - res://assets/ui/fonts/Orbitron-VariableFont_wght.ttf
  This repo can also use:
    - res://assets/ui/fonts/Orbitron-VariableFont_wght.ttf (default if present)

Option B (FREE alternatives that also look great):
- Oxanium (Google Fonts) `https://fonts.google.com/specimen/Oxanium`
- Exo 2 (Google Fonts)   `https://fonts.google.com/specimen/Exo+2`

Option C (PAID, closest to the vibe):
- Bank Gothic / Eurostile-style families (license varies by vendor).

After adding the font file:
- Open MainMenu scene OR run the game.
- In the Inspector for MainMenu (script exports), set:
  - title_font_path (and optionally subtitle_font_path)
